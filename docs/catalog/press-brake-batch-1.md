# 折弯模具第一批本地实施记录

执行日期：2026-10-31 至 2026-11-01。此记录区分页面接入、技术依据、图片采集和实际验收，不表示本轮已经发布。目录仍以 `content/catalog/products.json` 为唯一数据源。

## 页面映射与设计

| 类型 | 页面 | 处理及边界 |
| --- | --- | --- |
| 直身上模 | `/products/pb-straight-punch` | 复用原页、原 URL 和原白底图；保留刀尖角度/R、工作高度/刀柄、长度/分段及上下模组合载荷核对。没有另建“标准直刀”同义页。 |
| 尖刀/锐角上模 | `/products/pb-acute-punch` | 新增采购入口。工作夹角较小，用于锐角及压死边预折；角度不等于成品角度，压平另需工序。不是把现有直刀改成尖刀。 |
| 单V下模 | `/products/pb-single-v-die` | 新增下模入口。单个固定V槽，分别说明开口宽度、槽角和模肩R；安装底座及允许线载荷按组合核对。 |
| 双V下模 | `/products/pb-double-v-die` | 新增下模入口。两个固定V槽，分别核对几何、位置、换槽和载荷；区分翻转与同面移位，不宣称等同可调V。图示采用相对两面的可翻转结构。 |

三类新页使用现有 `ProductDetail`、`PageHero`、尺寸说明、相关产品和本页询价组件；不新增独立布局或配色。总览及产品列表继续使用已有分组导航，增加下模入口，快夹仍归附件。十个正式系列及原有八个模具/附件子页均保留。当前共33个产品、42个公开页面、11个折弯模具/附件子页。

新增内容、图片辅助文字及动态放大标签同步九种语言，每种871个英文键对应译文。SEO使用各页独立的采购意图、标题和描述；新页加入静态预渲染和 sitemap。未新增材料、硬度、板厚范围、额定吨位、认证或交期承诺。

## 调研依据和未采用内容

已在用户正式 Chrome 的[豆包原对话](https://doubao.com/chat/38450582371215362)分别追问尖刀、单V、双V，读取三次完整回答。回答仅作发现字段和来源的线索。

实际交叉核对的原厂页面：

- [Rolleri 21000](https://www.rolleritools.com/tools-6437/press-brakes/tools/type-r1-punches/21000)：提供锐角上模的角度、刀尖R、高度、有效高度和线载荷等独立字段，支持尖刀采购入口。其描述与参数表的材料不一致；没有复制材料、数值或评级。
- [Rolleri T80.06.88](https://www.rolleritools.com/tools-6437/press-brakes/tools/type-r1-dies/t800688.html)：V宽、槽角、R、高度和长度分别列出，支持单V下模的独立选型字段。没有将该型号规格当成本厂标准尺寸。
- [AMADA 2V reversible dies](https://www.amada.at/index.php/en/bending-technology/standardtools/multi-v-dies/2v-reversible-dies)：检索结果列出不同角度和成对开口；完整打开本次超时，不能记为完整详情已读。作为可翻转2V原厂线索保留，后续应补充原厂完整截面/目录核验。

豆包回答中的“所有鹅颈头部都是88°”“上下模必须同品牌体系”“固定板厚/开口倍数”“通用线载荷、硬度及安全系数”等泛化说法未接入。上下接口分别匹配对应夹座；最终配对还需实际截面、工件和行程，而不是只按品牌或单个角度判断。
