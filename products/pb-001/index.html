Products in This Series

Upper punches

  • Straight Press Brake Punches

    Straight-body upper punches for accessible bends. Specify the punch angle, tip radius, working height and tang profile together with the lower die.

    • Punch angle and tip radius
    • Working height and tang
    • Working length and sections
    View Details

  • Acute-angle Press Brake Punches

    Acute-angle upper punches for sharp bends and hemming pre-bends. Select the tip angle and radius with a suitable lower die.

    • Punch angle and tip radius
    • Working height and tang
    • Working length and sections
    View Details

  • Gooseneck Press Brake Punches

    Relieved upper punches for parts with return flanges. The gooseneck opening provides clearance while the tip forms the bend over a separate lower die.

    • Gooseneck opening and clearance
    • Punch angle and tip radius
    • Working height and tang
    View Details

Lower dies

  • Single-V Press Brake Dies

    Lower dies with one fixed V groove. Specify the V-opening, groove angle and shoulder radii for the material and bend drawing.

    • V-opening and groove angle
    • Die height and mounting base
    • Working length and sections
    View Details

  • Double-V Press Brake Dies

    Lower dies with two fixed V grooves. Specify both openings and the groove arrangement; the changeover method depends on the die and holder.

    • V1 and V2 openings
    • Die height and mounting base
    • Working length and sections
    View Details

  • Multi-V Press Brake Dies

    Multi-V lower dies combine several fixed grooves in one block. Specify each groove and the supporting holder before selecting a working face.

    • Groove schedule and block section
    • Support, indexing and working height
    • Working length and sections
    View Details

Working profiles

  • Radius Bending Tooling

    Tooling for radius bending. Confirm the upper-tool profile, any cylindrical insert and holder, and the matching lower die from the part and tooling drawings.

    • Part radius and tool radius
    • Insert and holder interface
    • Lower-die opening and angle
    View Details

  • U-profile Forming Tooling

    Tooling for U-shaped sections. Confirm the forming sequence, tool profiles and part-release direction from the finished channel drawing.

    • Channel inner width and flanges
    • Bottom profile and sheet thickness
    • Release direction and working length
    View Details

  • Custom Profile Forming Tooling

    Matched punches and dies for custom pressed sheet sections. Provide the finished profile, forming depth, sheet thickness and release direction.

    • Finished profile and forming depth
    • Material and forming operation
    • Tool closure and part release
    View Details

Applications

  • Container Forming Tooling

    Custom tooling for container forming. The finished part drawing defines the required section, dimensions and forming sequence.

    • Panel profile, pitch and depth
    • Sheet thickness and forming length
    • Feed direction and forming sequence
    View Details

  • Light Pole Bending Tooling

    Tooling for bending light pole shells. Confirm the shell section, taper, bending sequence and unloading clearance for the press brake.

    • End sections and taper
    • Forming method and lower tool
    • Machine span and working length
    View Details

Clamping accessories

Dimensions & Fit

Made to your application and approved drawing. Share the following dimensions so we can confirm a suitable size, material and quotation.

Length and sections · L
Specify total working length and individual segment lengths, including any special end sections.
Tool type and working profile
Identify the tool type first. Supply punch angle and tip radius, die opening and shoulder radii, forming-cavity profile or clamp interfaces as applicable.
Clamping interface
Supply the tang and mounting-interface drawing, machine model and clamping-system details.

Machine Compatibility

Confirm the press-brake clamping interface, working height and required tooling profile with your machine specifications. Include the sheet material, thickness and bend drawing.
